# Portfolio Gabriel Machado 2.0.0

## Uma nova base para crescer

A versão 2.0 reconstrói o portfólio como um produto Angular preparado para evolução contínua. O conteúdo deixa de depender de marcação repetida e passa a ser dirigido por dados tipados, componentes isolados e serviços para idioma, tema, SEO e instalação.

## Principais entregas

- novo projeto MR Serviços no catálogo;
- Alcateia do Ensino mantida como case principal;
- experiência responsiva para desktop, tablet e mobile;
- português, inglês e espanhol;
- temas claro e escuro;
- instalação como PWA e cache offline;
- artes, monograma e banners sociais próprios;
- SEO completo e dados estruturados;
- deploy contínuo no Netlify;
- governança e segurança para repositório público.

## Atualização

Esta é uma mudança de arquitetura. Use Node.js 22, execute `npm ci` e gere o build com `npm run build`. O diretório de publicação do Netlify é `dist/portfolio-gabriel/browser`.
