# Política de segurança

## Versões suportadas

| Versão           | Suporte |
| ---------------- | ------- |
| 2.x              | Sim     |
| 1.x e anteriores | Não     |

## Relatar uma vulnerabilidade

Não abra uma issue pública para uma possível vulnerabilidade.

Use uma das opções abaixo:

1. abra um **Private vulnerability report** na aba Security do GitHub, quando disponível;
2. envie uma descrição para `gabrielsolucoesemsoftware@gmail.com` com o assunto `SECURITY — portfolio-gabriel`.

Inclua descrição, impacto, passos mínimos para reprodução, ambiente e evidências sem dados pessoais de terceiros. O recebimento será confirmado em até 5 dias úteis. O prazo de correção dependerá da gravidade e será comunicado de forma privada.

## Escopo

São relevantes falhas na aplicação, pipeline, configuração do Netlify, dependências e exposição acidental de dados. Engenharia social, indisponibilidade de serviços externos e testes destrutivos estão fora de escopo.
